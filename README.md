# Binary Search Simulator

A self-contained, interactive teaching simulator for Binary Search.

## Live site

After GitHub Pages is enabled, the simulator will be available at:

https://gautamhimanshuhg7-bit.github.io/binary-search-simulator/

## Features

- Clickable pseudocode lines, including cycling through repeated executions
- Play, pause, previous, next, and reset controls
- Adjustable playback speed
- Custom comma-separated sorted arrays and integer targets
- Found, not-found, empty-array, and duplicate-value handling
- Sorted-input validation
- Keyboard controls: Left/Right arrows, Space, and Home
- No external JavaScript libraries, CSS frameworks, or API calls

## Enable GitHub Pages

The repository files are published from the `main` branch root.

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**.
4. Click **Save**.
5. Wait for the Pages deployment to finish, then open the live site URL above.

## Use inside PowerPoint

To display the live simulator inside a slide without switching tabs, insert a PowerPoint web-viewer add-in and set its URL to the live site URL above. The slide/add-in must be tested in the exact PowerPoint version and device that will be used in class. The embedded web page requires internet access to load from GitHub Pages.

## Local use

Open `index.html` in a modern browser. The page is designed to work without network dependencies.
